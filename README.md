# 生活规划 App（Life Planner）

一个**只在你电脑本地运行**的个人生活规划应用，把学习、锻炼、饮食、娱乐、课表、音乐和备忘集中到一个页面管理。数据全部保存在浏览器本地，关机、重启、刷新都不会丢失。

> 当前版本：v2.0 ｜ 纯本地应用：无登录、无联网、无云数据库、无部署

---

## 1. 这个项目解决什么问题

日常学习生活中有很多零散信息需要管理，散落在不同地方很容易乱：

- 学习任务、截止日期记在脑子里或纸片上，容易忘记；
- 每周固定锻炼安排、每天吃了什么、热量多少，没有统一的记录；
- 学期课表（还要区分单双周）和娱乐活动安排各有各的记法；
- 备忘录、本地音乐播放也要单独打开别的工具。

本项目把这些统一放进**一个本地网页应用**里，打开就能看到「今天该做什么」：

- 首页直接汇总今天的**学习任务、课表、待办、锻炼、娱乐、饮食热量**；
- 所有数据存在你自己的浏览器里（IndexedDB），**不上传任何服务器**；
- 音乐直接从你的本地文件夹播放，不复制文件、不占用额外空间；
- 提供数据导出/导入备份，换浏览器或清数据也能恢复。

适合个人自用、学习前端技术、或作为本地工具长期维护。

## 2. 主要功能

| 模块 | 功能 |
|---|---|
| 🏠 首页预览 | 按时段问候；汇总今天的学习任务、今日课表、未完成备忘、今天锻炼、今天娱乐、今日饮食热量；显示当前学期第几周 |
| 📚 学习计划 | 按学科管理任务；任务可拆子任务并显示进度；支持截止日期、逾期高亮；**勾选父任务时子任务自动联动** |
| 💪 锻炼计划 | **日历视图**展示每周锻炼安排；按日期标记「已完成」打卡；本周概览快捷切换；添加/编辑/删除锻炼条目 |
| 🍎 饮食计划 | 记录每天早/午/晚/加餐吃了什么；统计当日热量；常用食物一键带入；近 7 天热量趋势图 |
| 🎮 娱乐计划 | 月历安排娱乐活动（外出/聚会/运动/游戏/影视等）；即将到来列表；活动完成标记 |
| 📅 学期课表 | 填开学日期自动计算周次；**支持单双周课程**；节次时间可自定义；支持周末显示开关 |
| 🎵 音乐播放 | 选择本地文件夹直接播放音频（mp3/flac/m4a/wav/ogg 等）；记住授权与播放状态；循环/随机/音量控制 |
| 📝 备忘录 | 快速添加待办（回车即建）；勾选完成、置顶、可选截止日期；逾期提醒 |
| ⚙️ 数据与设置 | **导出/导入全部数据备份**；学期、节次、主题（浅/深色）、首页卡片显示开关；音乐授权管理 |
| 💾 手动保存 | 顶栏「保存」按钮可手动持久化，并显示上次保存时间 |

## 3. 安装方法

### 环境要求

- **Node.js 18+**（推荐 20+）
- **npm**（Node 自带）
- 浏览器：**Chrome 或 Edge**（Chromium 内核，音乐功能依赖 File System Access API，Firefox/Safari 不支持）

### 步骤

```bash
# 1. 进入项目目录
cd life-planner

# 2. 安装依赖（首次运行必须）
npm install

# 3. 启动开发服务器
npm run dev
```

浏览器自动打开（或手动访问）`http://localhost:5173` 即可使用。

> 提示：如果你的 npm 在 PowerShell 下报 `npm.ps1 无法加载`，改用 `npm.cmd install`。

### 运行测试

```bash
npm test          # 运行全部测试（Jest）
npm run build     # 打包生产版本到 dist/
```

## 4. 使用方法

### 首次使用（建议顺序）

1. **设置学期**：进入「学期课表」→ 点「学期设置」→ 填写学期名称和开学日期（**须为周一**）。顶栏和首页会显示「第 X 周 · 单/双周」。
2. **添加课程**：在课表网格中点击空格添加课程（名称/星期/节次/地点/每周·单周·双周/颜色）。
3. **建学习任务**：「学习计划」→ 先「+ 新增」学科（带颜色），再「+ 新增任务」，可填截止日期和子任务。
4. **安排锻炼**：「锻炼计划」→ 点日历中的日期 → 「+ 添加锻炼」；练完当天点「标记完成」打卡。
5. **记录饮食**：「饮食计划」→ 默认显示今天，在早/午/晚/加餐中添加食物，勾选「存为常用」可复用。
6. **播放音乐**：「音乐播放」→ 「选择音乐文件夹」→ 授权后自动生成播放列表。

### 日常使用

- 每天打开首页即可看到今天的任务、课程、待办和热量；
- 顶栏右侧可随时点 **「💾 保存」** 手动保存，显示上次保存时间；
- 数据会自动保存，**刷新/重启/关机都不会丢失**；
- 建议定期到「数据与设置」→「导出全部数据」做备份（得到一个 JSON 文件）；
- 换电脑或误删数据时，「导入数据」选择备份文件即可恢复（导入前会自动先导出一份当前数据）。

### 注意事项

- 必须通过 `http://localhost:5173` 访问，**不要**直接双击 `index.html`（音乐授权和本地存储需要安全上下文）；
- 音乐文件不复制进应用，只是读取授权；更换文件夹或浏览器需重新授权；
- 数据存在浏览器 IndexedDB 中，**清除浏览器数据会清掉应用数据**，请先导出备份。

## 5. 输入输出示例

### 示例一：添加一门课程并查看课表

**输入**：在课表模块「学期设置」填写开学日期 `2026-09-07`（周一）；点周一第 1 节空格，添加课程「高等数学 / 地点 A101 / 每周」。

**输出**：
```
顶栏：2026年9月7日 周一 | 第 1 周 · 单周
课表网格：
┌─────────┬──────────────┐
│ 节次     │ 周一          │
├─────────┼──────────────┤
│ 第1-2节  │ 高等数学 A101 │
│ 08:00   │              │
└─────────┴──────────────┘
```

### 示例二：创建带子任务的学习任务并跟踪进度

**输入**：学习计划 → 学科「数学」→ 任务「第三章习题」，子任务输入：
```
第1题
第2题
第3题
```

**输出**：
```
□ 第三章习题 [数学] 截止: 2026-09-10
  ▓▓▓░░ 33%
  ☑ 第1题
  ☐ 第2题
  ☐ 第3题
（勾选父任务后：子任务全部自动勾选，任务变已完成）
```

### 示例三：记录饮食并统计热量

**输入**：饮食计划（今天）→ 午餐 → 添加食物：`米饭 / 1碗 / 200千卡`，再添加 `鸡胸肉 / 150g / 165千卡`。

**输出**：
```
2026-09-07 (今天)
早餐（0 千卡）   午餐（365 千卡）   晚餐（0 千卡）   加餐（0 千卡）
今日热量：365 千卡
近 7 天趋势：███░░░░
```

### 示例四：锻炼打卡

**输入**：锻炼计划 → 点今天的日期 → 「+ 添加锻炼」→ `跑步 / 30分钟 / 19:00-19:30`；练完后点「标记完成」。

**输出**：
```
2026-09-07（周一）[今天]
  ● 跑步  30分钟 · 19:00-19:30   [编辑] [删除]
  [✓ 已完成]
日历：今天格子上显示 ✓ 标记
```

### 示例五：导出/导入备份

**输入**：数据与设置 → 「导出全部数据」。

**输出**：浏览器下载文件 `life-planner-backup-2026-09-07.json`，内容形如：

```json
{
  "version": 1,
  "settings": { "semesterName": "2026-2027 第一学期", "semesterStartDate": "2026-09-07", "theme": "light" },
  "subjects": [{ "id": "m1", "name": "数学", "color": "#4f46e5" }],
  "studyTasks": [],
  "exerciseEntries": [],
  "exerciseCompletedDates": [],
  "dietRecords": [],
  "entertainments": [],
  "courses": [],
  "memos": [{ "id": "x1", "text": "交作业", "done": false, "pinned": false, "order": 1 }]
}
```

之后「导入数据」选择该文件 → 确认覆盖 → 所有模块数据恢复。

## 技术栈

- **前端**：React 18 + TypeScript + Vite
- **状态管理**：zustand
- **本地存储**：IndexedDB（`idb`）
- **音乐**：File System Access API
- **测试**：Jest + ts-jest + @testing-library/react（87 个用例）
