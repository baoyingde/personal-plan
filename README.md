# 生活规划 App（Life Planner）

一个**前后端完整**的个人生活规划应用：前端用 React 构建 9 大功能模块，后端用 Node.js + Express + MySQL 存储数据。支持用户注册登录，数据保存在服务器数据库，任何设备登录同一账号即可同步。

> 当前版本：v3.1 ｜ 前端 React + 后端 Express + MySQL ｜ 支持用户登录、多设备数据同步、QQ音乐在线播放

---

## 1. 这个项目解决什么问题

日常学习生活中有很多零散信息需要管理，散落在不同地方很容易乱：

- 学习任务、截止日期记在脑子里或纸片上，容易忘记；
- 每周固定锻炼安排、每天吃了什么、热量多少，没有统一的记录；
- 学期课表（还要区分单双周）和娱乐活动安排各有各的记法；
- 备忘录、音乐播放也要单独打开别的工具。

本项目把这些统一放进**一个应用**里，打开就能看到「今天该做什么」：

- 首页直接汇总今天的**学习任务、课表、待办、锻炼、娱乐、饮食热量**；
- **用户注册登录**，所有数据存在服务器 MySQL 数据库中，**换设备登录同一账号数据一致**；
- **在线音乐搜索播放**（QQ 音乐源），无需准备本地音乐文件；
- 学期课表支持单双周，锻炼计划日历打卡，饮食自动统计热量。

适合个人自用、学习前后端全栈开发、或作为开源项目持续维护。

## 2. 主要功能

| 模块 | 功能 |
|---|---|
| 👤 用户系统 | 注册/登录（JWT 认证，密码 bcrypt 哈希加密存储）；多用户数据隔离 |
| 🏠 首页预览 | 按时段问候；汇总今天的学习任务、今日课表、未完成备忘、今天锻炼、今天娱乐、今日饮食热量；显示当前学期第几周 |
| 📚 学习计划 | 按学科管理任务；任务可拆子任务并显示进度；支持截止日期、逾期高亮；**勾选父任务时子任务自动联动** |
| 💪 锻炼计划 | **日历视图**展示每周锻炼安排；按日期标记「已完成」打卡；本周概览快捷切换；添加/编辑/删除锻炼条目 |
| 🍎 饮食计划 | 记录每天早/午/晚/加餐吃了什么；统计当日热量；常用食物一键带入；近 7 天热量趋势图 |
| 🎮 娱乐计划 | 月历安排娱乐活动（外出/聚会/运动/游戏/影视等）；即将到来列表；活动完成标记 |
| 📅 学期课表 | 填开学日期自动计算周次；**支持单双周课程**；节次时间可自定义；支持周末显示开关 |
| 🎵 音乐播放 | **QQ 音乐在线搜索播放**（国内服务器直连，响应快）；浏览器端逐个尝试播放链接；VIP 歌曲自动跳转 QQ 音乐页面 |
| 📝 备忘录 | 快速添加待办（回车即建）；勾选完成、置顶、可选截止日期；逾期提醒 |
| ⚙️ 数据与设置 | 账号信息、**修改密码**、退出登录；学期、节次、主题（浅/深色）、首页卡片显示开关 |

**所有数据均存储在服务器 MySQL 数据库中**（第三版起），不再是浏览器本地存储。

## 3. 安装方法

### 环境要求

- **Node.js 18+**（推荐 20+）
- **npm**（Node 自带）
- **MySQL 8.0**（数据库）
- 浏览器：Chrome / Edge / Firefox / Safari

### 步骤

#### 3.1 初始化数据库

```bash
# 1. 进入后端目录
cd server

# 2. 安装后端依赖
npm install

# 3. 配置数据库连接（复制模板并填写你的 MySQL 密码）
cp .env.example .env
#   Windows: copy .env.example .env
#   编辑 .env，填写 DB_PASSWORD 为你的 MySQL root 密码

# 4. 创建数据库和表（只需一次）
node src/db/init.js
```

#### 3.2 启动后端

```bash
cd server
node src/index.js
# 后端启动在 http://localhost:3001
```

#### 3.3 启动前端

```bash
# 回到项目根目录
cd ..

# 安装前端依赖
npm install

# 启动开发服务器
npm run dev
# 前端启动在 http://localhost:5173
```

浏览器打开 `http://localhost:5173` → 注册账号 → 开始使用。

### 运行测试

```bash
npm test                      # 前端测试（82 个用例）
cd server && node test/verify.js   # 后端全链路验证（需后端已启动）
```

## 4. 使用方法

### 首次使用

1. **注册账号**：打开应用 → 注册（用户名 + 密码）→ 自动登录。
2. **设置学期**：进入「学期课表」→「学期设置」→ 填学期名称和开学日期（须为周一）。
3. **添加课程**：课表网格中点击空格添加课程（名称/星期/节次/地点/每周·单周·双周/颜色）。
4. **建学习任务**：「学习计划」→ 先新增学科（带颜色），再新增任务（可填截止日期和子任务）。
5. **安排锻炼**：「锻炼计划」→ 点日历日期 → 添加锻炼；练完当天「标记完成」打卡。
6. **记录饮食**：「饮食计划」→ 在早/午/晚/加餐中添加食物，可「存为常用」。
7. **在线听歌**：「音乐播放」→ 搜索歌曲 → 点击即播，无需本地文件。

### 日常使用

- 每天打开首页即可看到今天的任务、课程、待办和热量；
- 数据自动保存到服务器数据库，**换设备/换浏览器登录同一账号数据一致**；
- 学期、主题、首页卡片等设置保存在服务器，随账号同步；
- 退出登录：数据与设置 →「退出登录」。

### 注意事项

- 前端（5173）与后端（3001）需**同时运行**；
- 数据库密码等敏感信息配置在 `server/.env`（已被 `.gitignore` 排除，不会提交到 GitHub）；
- 在线音乐为第三方公开接口的试听用途对接，商用请使用授权音乐服务。

## 6. 后台管理

内置一个**管理后台**（管理员专用），用于管理用户和查看数据。

### 6.1 进入方式

在地址栏加 `?admin` 参数访问管理端：

```
http://localhost:5173/?admin
```

### 6.2 管理员账号

- 用 SQL 把某账号提升为管理员：`UPDATE users SET role='admin' WHERE username='你的账号';`
- 管理后台**可直接将普通用户提升为管理员**（用户列表 → 设为管理员），无需手动 SQL
- 也可取消管理员权限（变为普通用户，不能操作其他管理员）

### 6.3 功能

| 模块 | 功能 |
|---|---|
| 📊 仪表盘 | 用户总数、今日注册、管理员数、已禁用数、各模块数据量、近 7 天注册趋势 |
| 👥 用户管理 | 用户列表（搜索/分页）、用户详情（业务数据只读查看）、禁用/启用、**设为管理员/取消管理员**、重置密码、删除用户 |
| 📜 操作日志 | 记录管理员的关键操作（禁用/启用/重置密码/设为管理员/删除用户） |

### 6.4 安全

- 所有管理接口校验 `role=admin`，普通用户访问返回 403；
- 删除用户需二次确认，级联删除其全部数据；
- 操作日志可追溯。

## 7. 项目结构

```
│   ├── api/client.ts       # API 客户端（token 注入、所有接口封装）

│   ├── db/schema.sql       # 数据库结构（11 张表）
│   ├── db/admin_migration.sql # 管理后台迁移（role 字段 + admin_logs 表）
│   ├── src/index.js        # 后端入口
│   ├── src/routes/         # API 路由（auth/admin/memos/study/exercise/diet/entertainments/courses/music）
│   ├── src/middleware/     # JWT 认证中间件（含 requireAdmin）

```

## 8. 技术栈

- **前端**：React 18 + TypeScript + Vite + zustand
- **后端**：Node.js + Express + mysql2
- **数据库**：MySQL 8.0
- **认证**：JWT（jsonwebtoken）+ bcrypt 密码哈希
- **管理后台**：角色权限（admin/user）+ 操作日志
- **音乐**：QQ 音乐公开搜索接口（c.y.qq.com），浏览器端直连播放
- **测试**：Jest + Testing Library（前端 91 用例）、后端全链路验证
